# Werewolf 20 rules ambiguities

- Chronicle-specific Gift teachers, spirit relationships, and unusual starting
  Gifts require a recorded Storyteller ruling.
- Fomori powers and taints vary by framework. Only verified packages drive
  automatic budgets; other entries remain citation-only.
- Fallen Changing Breeds and Black Spiral content require mature-content opt-in
  and a recorded Storyteller approval.
- Renown and Rank changes remain recorded table decisions; the application does
  not automatically adjudicate deeds or challenge outcomes.
- Historical experience prices remain unchanged if a later catalog correction
  affects future purchases.
