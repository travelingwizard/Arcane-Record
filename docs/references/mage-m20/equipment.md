# Mage M20 Equipment Reference

## Status and use

This document organizes the supplied equipment research into stable catalog
records for Arcane Record. It is a reference preview, not a rules engine.
Statistics and citations remain unverified until checked against the named
books. Character exports store ownership details and stable IDs, not the
catalog text below.

Families:

- `mundane`: ordinary personal, civilian, and historical equipment;
- `military`: restricted conventional weapons and armor;
- `technocratic`: Technocratic hardware and Inspired Science;
- `mystic`: mystic or otherwise supernatural objects;
- `malign`: Nephandic objects and mature material, hidden by default.

Categories are `melee`, `ranged`, `armor`, and `gear`. Statistics are preserved
as reference text because ranges, damage expressions, and special cases are
not uniform enough to turn into reliable rules without source review.

## Character-owned data

Catalog entries are immutable reference data. A selected or custom item stores:

- an owned UUID;
- an optional catalog definition ID;
- an editable name and category;
- a character-written description;
- integer quantity;
- equipped/carried state;
- character notes and addition timestamp;
- an optional unresolved source name for unknown imported definitions.

Custom equipment requires only a name and description. No equipment entry
changes Attributes, damage, soak, dice pools, or other character data
automatically.
