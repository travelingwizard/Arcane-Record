# Vampire: The Masquerade 20th Anniversary source manifest

Arcane Record stores concise, original character-facing summaries and stable
machine identifiers. It does not ship source PDFs, artwork, logos, fonts, or
extended rules text.

| Source ID | Source | Use | Default |
| --- | --- | --- | --- |
| `v20.core` | Vampire: The Masquerade 20th Anniversary Edition | Required modern Vampire rules and catalogs | On |
| `v20.companion` | V20 Companion | Titles, prestation, technology, and character-facing social records | Off |
| `v20.ghouls-revenants` | Ghouls & Revenants | Ghoul and revenant creation, families, Traits, organizations, and advancement | On for Ghoul/Revenant |

The four-page interactive ghoul sheet is a field-hierarchy reference only and
is never packaged with the application.
