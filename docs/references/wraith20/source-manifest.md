# Wraith 20 source manifest

The Wraith 20 core book is required. Handbook for the Recently Deceased and
Book of Oblivion are modern optional sources. Haunts, Mediums, The Risen, and
Buried Secrets are optional legacy sources whose selectable mechanics require
W20 compatibility verification. Existing selections remain visible if their
source is disabled.

Arcane Record stores concise original summaries, stable IDs, rule status, and
book/page citations. It does not package source PDFs, logos, artwork, textures,
portraits, or fonts.

## Automation boundaries

- The app validates objective creation budgets but does not determine a
  character's emotional relevance, Transcendence, or Harrowing outcomes.
- A linked Shadow is a separate browser-local character record. Concealing it
  in the interface is not a security boundary.
- Spectre material requires mature-content opt-in and a recorded Storyteller
  approval.
- Risen is an advanced transformation recorded on a Wraith; it is not a normal
  first-step creation family.
