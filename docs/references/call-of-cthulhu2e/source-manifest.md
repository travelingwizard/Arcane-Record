# Call of Cthulhu Second Edition source manifest

The runtime contains concise, original character-facing summaries and stable references only. Source PDFs, illustrations, maps, logos, fonts, scenarios, and extended tables are not packaged.

| Source ID | Source | Use | Default |
| --- | --- | --- | --- |
| `coc2e.core` | *Call of Cthulhu Second Edition*, updated reprint | Required rules authority: creation, skills, combat, sanity, magic, and Keeper references | On |
| `coc2e.1920s` | *1920s Sourcebook*, updated reprint | Optional occupations, skills, equipment, finances, and Previous Experience | Off |

The original two-page character sheet and Keeper screen determine field hierarchy only. *BRP Classic* is a cross-checking reference and never overrides the Call of Cthulhu rules.

Implemented catalog namespaces are `occupation`, `skill`, `weapon`, `equipment`, `spell`, `tome`, and `insanity`. Mythos spells and tomes are Keeper-only and reach an Investigator through an explicit grant.
