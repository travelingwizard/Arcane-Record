# Band of Blades source manifest

## Runtime sources

| Source ID | Source | Use |
| --- | --- | --- |
| `bob.core` | Band of Blades, 2019 | Rules authority for Legionnaires, the Legion, command roles, the Chosen, campaign procedures, missions, and advancement |
| — | Band of Blades Sheets, color and B&W | Field hierarchy and workflow reference only |

The application stores stable IDs, source pages, concise original summaries, and structured user records. It does not package the source PDFs, fixed page layouts, art, logos, fonts, adventures, or extended rules text.

## Verification and ambiguity register

- Fictional position, effect, consequences, corruption outcomes, death, compromises, mission details, and Broken behavior remain table decisions.
- Published mission mechanics are represented; authored missions and adventure prose are excluded.
- Command roles operate on one authoritative Legion record to avoid conflicting resource totals.
- Chosen are linked records. Broken are reference and threat-tracking panels inside the Legion record.
- Cross-device synchronization is not implied; all links and revision checks are browser-local.
