# Mouse Guard Second Edition source manifest

The application contains original, concise catalog summaries and structured rules data only. It does not package PDF pages, artwork, logos, fonts, comics, or missions.

| Source ID | Source | Status | Character-facing scope |
| --- | --- | --- | --- |
| `mg2.core` | Mouse Guard Roleplaying Game Second Edition | Required | Recruitment, ranks, settlements, skills, traits, Wises, equipment, conflicts, rewards, and advancement |
| `mg2.new-rules` | New Rules, New Missions | Optional, default off | Flintrust, Sandmason, Grasslake, mounts, mace, and new conflict equipment |
| — | GM record sheet r6 | Layout reference only | Patrol roster, mission, relationship, condition, and reward hierarchy |

Primary Recruitment citations are core pp. 299–313. Catalog definitions retain their individual source/page fields. The optional source is filtered without deleting previously selected records.

## Ambiguity register

- Patrol-wide specialty uniqueness is a warning when no linked patrol record is available.
- Guard Captain availability is recorded as a group/GM approval rather than silently permitted.
- Fictional appropriateness, twists, conditions, compromises, and promotion are human decisions; the application records outcomes but does not decide them.
- Supplement missions are out of scope and are not represented as selectable character content.
