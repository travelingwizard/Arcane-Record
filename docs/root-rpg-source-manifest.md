# Root: The Roleplaying Game source manifest

The core book is required. Travelers & Outsiders and the Clearing Booklet are optional official sources. The supplied R&E chapter and Dealer sheet are classified as an incomplete official preview; self-contained records retain that provenance and absent dependencies remain reference-only.

The 2022 print-friendly core playbooks and Travelers & Outsiders playbooks cross-check field hierarchy. Earlier play-material packets are revision references only and never create duplicate definitions.

Runtime content excludes artwork, logos, maps, fixed playbook pages, adventure prose, and long source passages. Catalog entries use stable IDs, printed page citations, and concise original summaries.
