# Vampire: The Dark Ages 20th Anniversary module

The `vampire-dark-ages20` module uses the core rulebook as its rules authority. The official interactive sheet informed field hierarchy only; no PDF art, logo, borders, texture, or font ships with Arcane Record.

## Runtime boundary

- Character records remain browser-local and pass through the shared repository and Zod boundaries.
- Stable `dav20.*` catalog identifiers retain source and page provenance.
- Demon-associated and antagonist-oriented material is hidden until mature content is enabled and a Storyteller approval is recorded.
- The creator models the standard fledgling baseline before optional maturation. Manual sheets do not infer a creation history.
- Starting Blood Pool rolls use browser cryptographic randomness and preserve the die, modifiers, total, method, and timestamp.
- Experience is ledger-derived. Historical prices remain unchanged, and Background XP requires explicit Storyteller discretion.

## Design contract

The editor and creator use the same shared shell, semantic fields, cards, notices, navigation, Settings, themes, and responsive behavior as Mage. Game-specific classes may describe domain layout only and may not replace shared colors, surfaces, typography, focus behavior, or controls.
