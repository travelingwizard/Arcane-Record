# Module Builder accessibility contract

- Drag/drop is an enhancement. Add, move up/down, move to section, insert, duplicate, copy/paste, and delete operations have keyboard-operable buttons.
- Structural changes announce through a polite live region and restore focus to the moved or adjacent item.
- Desktop uses library, canvas, and inspector landmarks. Mobile uses explicit tabs/drawers rather than compressed columns.
- Controls have real labels, visible focus, semantic headings, non-color status text, reduced-motion support, and practical 44px targets.
- Preview supports desktop and 320px modes and must not overflow at the page level.
- Destructive operations require confirmation or a recoverable undo transaction.
