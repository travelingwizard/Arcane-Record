## Cross-cutting findings

- Shared application chrome, semantic design tokens, Settings, autosave, import/export, and responsive navigation are reusable across all editors.
- Dots, numeric fields, text, grouped fields, wheels, damage, and selected catalog records already have trusted renderers.
- Repeating generic records, editable tables, generic catalog pickers, resource transactions, linked-record snapshots, and complex workflow editors are the largest declarative gaps.
- Game-owned pure rules engines should remain authoritative until equivalent behavior is represented and parity-tested through the safe DSL.
